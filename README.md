# 📋Project Aura - The Northern Realm

Welcome to **Project Aura**, a text-based fantasy role-playing game.
 This is a personal project I’m developing to study and test my programming skills.
The game mechanics are inspired by tabletop role-playing games (such as the use of dice-rolling systems for character stats) and the graphic style of 1980s video games

## 🌐 The Landing Page

To showcase the game, I created a retro-style landing page using HTML and CSS.
 I wanted to create a dark fantasy atmosphere that fits the spirit I hope the game will have.

## ⌨️ Interesting CSS features i’ve seen and implemented:
- **Glassmorphism Header:** The top navigation bar appears as a dark, semi-transparent glass panel (`backdrop-filter: blur`). As you scroll down the page, the background images scroll beneath it and dynamically blur.

- **Infinite animated chains:** The side chains aren’t static. I used CSS `@keyframes` to animate the background’s position in a continuous loop, making them scroll down smoothly.

- **Pixel art drop shadows:** Instead of standard shading, I used `filter: drop-shadow` to create crisp, retro shadows that perfectly follow the pixelated shape of the chains.
